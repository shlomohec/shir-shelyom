# שיר של יום בחול המועד

אפליקציית רשת קטנה (PWA) שמציגה את שיר של יום לפי התאריך העברי, לשיטת הגר"א, בשידור חי בכתובת:
https://shlomo-hecht.com/shir-shelyom/

## קבצים

- `index.html`, `app.js` - האפליקציה: בחירת תאריך, מתג ארץ ישראל / חוץ לארץ, חוקי משנה תמיד ז׳ ד׳ לימי חול וטבלת המועדים.
- `tehillim.js` - נוסח המזמורים (מקרא על פי המסורה, ניקוד ללא טעמים).
- `manifest.webmanifest`, `sw.js` - התקנה כאפליקציה ועבודה לא מקוונת.
- `gra.jpg`, `icons/` - תמונת הגר"א (ייחוס מסורתי) ואייקונים.
